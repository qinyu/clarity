# 主题菜单优先聚焦已保存的主题

B · Define 已确认

## 用户故事

作为用单键操作 Clarity 仪表的人，我希望打开主题选择菜单时，焦点落在已经保存的主题上。进入后再次长按确认时，我可以保留原来的选择。

## 范围

这次调整 Day / Night 主题选择菜单打开时的焦点。短按继续浏览选项，长按继续确认焦点所在的选项。已保存标记、主题保存和车灯触发临时换色沿用现有规则。其他设置菜单保持原有打开焦点。

## 主成功路径

1. 我从仪表进入设置，打开主题选择菜单。
2. 菜单聚焦当前已保存的主题。我可以直接长按保留它，也可以短按浏览其他选项。
3. 我长按确认另一个主题后，下次进入时菜单聚焦新保存的主题。

## 验收实例

| 编号 | 起始条件与操作 | 我看到的结果 |
| --- | --- | --- |
| B1 | 已保存 Day，打开主题菜单 | 焦点在 Day。 |
| B2 | 已保存 Night，打开主题菜单并直接长按确认 | 进入时焦点在 Night，再次进入时仍聚焦 Night。 |
| B3 | 已保存 Day，打开菜单后短按经过 Night，聚焦 Back 再长按返回。随后重新打开菜单 | 焦点仍在 Day。 |
| B4 | 已保存 Day，短按聚焦 Night 并长按确认。随后重新打开菜单 | 焦点在 Night，Night 显示为已保存选项。 |
| B5 | 已保存 Day，车灯触发让仪表临时显示 Night。在临时换色生效期间打开主题菜单 | 焦点仍在已保存的 Day。 |

## 业务决定

初始焦点以已保存的主题为准。车灯引起的临时换色期间，使用者直接长按仍能保留自己的选择。范围限定在主题菜单，便于独立验收并维持其他设置的既有操作。
