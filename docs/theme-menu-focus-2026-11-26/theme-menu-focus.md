# 打开主题菜单时聚焦上次保存的主题

- **角色与场景** 使用单键操作 Clarity 仪表的用户从设置进入 `Display → Theme`，查看或修改 Day / Night 偏好。
- **问题与成效** 当前菜单从 Day 开始高亮，即使 Night 已带有当前配置标记 `>`。调整后，用户进入菜单即可看到上次保存的选项并直接确认。
- **范围** 调整 `Theme` 子菜单打开时的初始焦点。已保存标记、按键顺序、手动保存流程以及车灯触发的临时换色沿用现有规则。亮度等其他菜单继续使用各自原有的焦点行为。
- **来源** 本轮用户原话「打开主题菜单时，我想直接选中上次保存的主题，车灯临时变色照旧。」用户回复「Q1、Q2 按建议」，确认进入及浏览只影响焦点，以及无法匹配的旧值回退到 Day 焦点、由用户手动保存。现状依据见[主题菜单](../../src/panels/config_panel.cpp#L559)、[主题默认值](../../include/managers/style_manager.h#L172)、[手动保存与菜单刷新](../../src/panels/config_panel.cpp#L363)、[车灯触发](../../include/definitions/interrupts.h#L82)及[配置保存与恢复](../../src/providers/storage_provider.cpp#L197)。

## US-001 重开主题菜单时定位到已保存主题

作为使用单键的 Clarity 用户，我希望每次打开主题菜单就高亮上次保存的主题，这样我可以直接确认它，也可以从该位置浏览其他选项。

**交付依赖** 无。

### 主成功路径

用户上次成功保存了 Night。打开 `Display → Theme` 时，Night 同时带有当前配置标记 `>` 和菜单高亮。用户直接长按即可确认 Night 并返回 Display。

### 业务规则

1. 每次打开 Theme 都读取当前偏好。已保存 Day 或 Night 时，对应选项获得高亮和 `>`，重启后仍按保存值定位。从未保存过主题时，默认 Day 获得高亮和 `>`。
2. 若加载出的主题偏好既不是 Day 也不是 Night，初始高亮落在 Day，两个主题选项均无 `>`。原值保留到用户成功长按保存一个有效选项。
3. 打开 Theme 只设置初始焦点。短按按 `Day → Night → Back → Day` 循环移动高亮，`>` 继续标记当前配置。打开和浏览均不触发主题保存或手动应用。
4. 长按高亮的 Day 或 Night，沿用现有保存流程。保存成功时回到 Display，设置菜单的标题和按键提示立即使用所选主题的颜色。长按 Back 返回设置主菜单，保留原主题偏好。
5. 车灯打开时，仪表按现有触发规则切到 Night 配色。车灯关闭时，仪表切到 Day 配色。两种车灯事件均保留已保存的主题偏好。手动保存时的配色刷新沿用设置菜单的现有范围，仪表即时配色继续由原有流程处理。

### 验收例

| 编号 | 起始条件与操作 | 预期结果 |
| --- | --- | --- |
| A1 | 已保存 Night，打开 Theme，直接长按确认，再打开 Theme | 两次进入均高亮 `> Night`。长按确认 Night 后回到 Display，显示 `Theme: Night`。 |
| A2 | 分别以已保存 Day、从未保存过主题两种状态打开 Theme | 两种状态均高亮 `> Day`。 |
| A3 | 已保存 Day，进入 Theme 后连续短按。观察一次循环，再移到 Back 并长按返回，随后重新打开 Theme | 高亮按 `Day → Night → Back → Day` 移动，浏览时 `>` 留在 Day。长按 Back 回到设置主菜单。重开时高亮 `> Day`。 |
| A4 | 分别验证 Day 改为 Night、Night 改为 Day。以原主题已保存且当前使用其配色为起点，保持车灯状态，短按移到另一主题并长按保存。回到 Display 后重启，再打开 Theme | 两个方向均在返回 Display 时看到新主题值，标题和按键提示立即显示所选主题的颜色。对照同一操作的基线记录，仪表即时配色的更新行为一致。重启后首次打开 Theme 时，所选主题同时获得高亮和 `>`。 |
| A5 | 已保存 Day，在仪表页把车灯由关切到开。观察换色后进入 Display，保持车灯开启，打开 Theme 并短按到 Night，暂不确认选项 | 仪表因开灯切到 Night 配色。Theme 刚打开时高亮 `> Day`，短按后高亮 Night，`>` 仍在 Day。打开 Theme 和短按期间均无主题保存或手动应用事件，可查验操作期间的应用和保存记录。 |
| A6 | 已保存 Night，在仪表页把车灯由关切到开，再切到关，每次都观察配色。保持车灯关闭，随后打开 Theme，暂不确认选项 | 仪表先切到 Night 配色，再切到 Day 配色。Theme 打开时高亮 `> Night`，操作期间的应用和保存记录没有这次菜单操作触发的事件。 |
| A7 | 已将 Brightness 保存为 50%，打开 Brightness 选项菜单 | 高亮仍在 0% 对应的首项，`>` 仍在 50% 对应项。 |
| A8 | 已载入一个不在 Day / Night 中的旧主题值，例如 `Legacy`。打开 Theme，使用 Back 返回后重开，再选择 Night 并长按保存 | 保存前两次进入均高亮 Day，两个选项均无 `>`，配置值仍为 `Legacy`。显式保存后，Display 显示 `Theme: Night`，再开 Theme 时高亮 `> Night`。 |
